# 경영현황 및 AI 고객 발굴 대시보드 구축 마스터 설계도 (Prompt Specification)

본 문서는 아무것도 없는 상태에서 AI 코딩 에이전트에게 프롬프트로 전달하여 현재와 **100% 동일한 기능, 비즈니스 로직, 데이터 무결성 및 UI/UX 디자인**을 완벽하게 재현하기 위한 시스템 설계 사양서입니다.

---

## 1. 개발 환경 및 기술 스택
- **Core Framework**: React 18+ (Vite 빌드 도구 활용)
- **Programming Language**: TypeScript (엄격한 타입 선언)
- **Styling**: Tailwind CSS (Tailwind 클래스 유틸리티 활용)
- **Icons**: `lucide-react`
- **Excel Library**: `xlsx` (SheetJS)
- **Hosting / Deploy**: GitHub Pages (GitHub Actions를 통한 자동 빌드 및 배포)

## 2. 데이터 아키텍처 및 유형 정의 (`src/types/index.ts`)

대시보드에서 다루는 모든 데이터의 정합성을 보장하기 위해 아래의 TypeScript 타입을 강제해야 합니다.

```typescript
// 1. 원시 엑셀 행을 파싱하여 메모리에 적재하는 매출 레코드 타입
export interface SalesRecord {
  id: string;
  year: number;          // 전기일에서 연도 추출 (예: 2026)
  month: number;         // 전기일에서 월 추출 (예: 4)
  dateStr: string;       // 원시 전기일 8자리 (예: "20260410")
  department: string;    // 영업 부서 (이름 열 매핑)
  budgetType: string;    // 예산(목) (예: "공개교육", "현장교육(OJT)")
  materialDetails: string; // 자재내역 (수강 강좌명)
  customerName: string;  // 고객사명 (공백이 정제된 trim 값)
  customerCode: string;  // 고객 코드
  salesAmount: number;   // 매출 계 (마이너스 취소 매출 포함)
  ksCert: boolean;       // KS인증 보유 여부 (엑셀 내 'O'인 경우 true)
  isoCert: boolean;      // ISO인증 보유 여부 (엑셀 내 'O'인 경우 true)
  memberStatus: string;  // 회원 상태 (예: "대기업", "중소기업", "비회원")
  branchOffice: string;  // 관할지부 (예: "전북", "광주전남제주")
}

// 2. 2026년 월별 목표 금액을 정의하는 KPI 타겟 타입
export interface TargetRecord {
  year: number;
  month: number;
  targetAmount: number;  // 원화(KRW) 기준 목표액
}

// 3. AI 고객 발굴 제안 리스트를 표현하는 추천 레코드 타입
export interface RecommendationRecord {
  customerName: string;
  ksCert: boolean;
  isoCert: boolean;
  isJeonbuk: boolean;
  branchOffice: string;
  memberStatus: string;
  hasPublicEdu: boolean;
  hasInHouseEdu: boolean;
  hasOjt: boolean;
  publicSales: number;
  inhouseSales: number;
  ojtSales: number;
  // 연도별로 과정명과 실제 환불 상쇄 횟수가 구조화된 타입
  topPublicMaterials: GroupedCourse[];
  topInhouseMaterials: GroupedCourse[];
  topOjtMaterials: GroupedCourse[];
}

export interface GroupedCourse {
  year: number;
  courseList: {
    name: string;
    count: number; // 취소 건이 누감 처리된 순 수강 횟수
  }[];
}
```

## 3. 데이터 로더 및 무결성 파서 (`src/utils/excelParser.ts`)

엑셀 파일을 FileReader를 통해 가져올 때 발생하는 한글 인코딩 깨짐 및 컬럼 위치 유동성을 완벽하게 제어해야 합니다.

### 🔑 파싱 핵심 알고리즘 규격
1. **2차원 원시 행렬 파싱**: 한글 인코딩 오류로 인한 객체 매핑 빗나감을 원천 방지하기 위해 `xlsx.utils.sheet_to_json<any[]>(sheet, { header: 1 })` 기법을 적용하여 데이터를 받아옵니다.
2. **동적 컬럼 인덱스 매칭**: 0번째 헤더 행에서 다음의 대표 단어들을 검색해 컬럼 인덱스를 추출합니다.
   - `전기일` ➡️ 연도 4자리, 월 2자리를 정밀하게 잘라내어 `year`와 `month` 숫자로 파싱
   - `이름` ➡️ 부서 매핑
   - `예산(목)` ➡️ 예산목 매핑
   - `자재내역` ➡️ 과정명 매핑
   - `고객명`, `고객` ➡️ 고객사명 매핑 (앞뒤 공백 강제 `trim()` 처리)
   - `매출 계`, `매출액` ➡️ Number 형변환 처리 (실패 시 0원 폴백)
   - `KS인증`, `ISO인증` ➡️ 'O' 또는 'o' 인지 검사해 Boolean 처리
   - `회원내역` ➡️ 회원 상태 문자열 처리
   - `관할지부`, `지부`, `관할` ➡️ 관할지부 매핑
3. **지부 컬럼 탐색 실패 시 폴백**: 엑셀 형식 변화로 지부 컬럼 검색에 실패할 경우, **가장 마지막 우측 열 인덱스를 폴백 인덱스(`length - 1`)로 강제 매핑**하여 전북 지부 판정을 구조적으로 복원합니다.

## 5. [마스터 피스] AI 경영분석 & 고객 발굴 탭 사양 (`ConsultingTab.tsx`)

본 대시보드의 핵심 비즈니스 로직과 가장 높은 피드백이 집중된 디테일이 집약된 컴포넌트입니다.

### 5.1 상단 AI 경영분석 브리핑 (아코디언 토글식 구성)
- **기본 상태**: 페이지 로드 및 탭 최초 진입 시 화면 효율을 극대화하기 위해 **기본적으로 접힌(collapsed) 상태**(`isBriefingExpanded = false`)로 표시됩니다.
- **제어바 UI**: 가독성 높은 흰색 박스 헤더바(`bg-white rounded-xl shadow-sm border border-slate-200 p-4 cursor-pointer hover:bg-slate-50`)를 누르면 접고 펴기가 작동합니다.
  - 우측에 `[경영분석 접기] ⬆️` / `[경영분석 펼치기] ⬇️` 표시기가 쉐브론 아이콘(`ChevronUp`, `ChevronDown`)과 동기화되어 표출됩니다.
- **기간 비교 및 브리핑 생성 로직**:
  - 독립된 기간 1(기준) 및 기간 2(대비) 연월을 설정하여 두 기간의 매출 증감액과 증감률을 실시간 분석합니다.
  - 이전 대비 매출 성장을 견인한 **부서별/품목별(자재내역)/고객사별 실적 브리핑**을 자연스러운 한국어 문맥으로 자동 작성합니다.
  - 마이너스 실적 상황에서도 한글 표현이 어색하게 틀어지지 않도록 어휘 선택 조건(증가액 없음 시 차선책 선방 부서 도출 등)을 분기 처리합니다.

### 5.2 하단 신규 사업 발굴 대상 (5열 rowSpan 연동 테이블)
- **조회 범위**: 공개교육 이력 보유 여부와 무관하게, 특정 기간 내 매출 실적이 1회라도 잡힌 **모든 고객사를 100% 다 땡겨옵니다.**
- **4단 토글 필터 컨트롤**: 상단 테이블 위에 독자적인 기간 설정 연월 필터와 함께 `공개교육 이력(O/X/전체) | 사내교육 이력(O/X/전체) | 현장교육 이력(O/X/전체) | 관할지부: 전북(O/X/전체)` 4단 필터를 제공하여 사용자가 이력 유무를 토글해 볼 수 있게 합니다.

#### 💡 [핵심] 취소선(음수 매출액) 카운트 보정 알고리즘
- 매출 환불이나 계약 취소 등으로 엑셀에 마이너스 매출액(`salesAmount < 0`)이 기록된 행이 유입될 경우, 과정 수강 횟수에서 단순히 `+1` 하는 것이 아니라 **`-1`을 상쇄 적용**하여 거래 취소 상황을 수강 횟수에 완벽히 정량 반영합니다.
- 취소 처리로 인해 특정 교육의 최종 누적 수강 횟수가 `0회` 이하가 된 교육과정은 세부내역 목록에서 자동 배제합니다.

#### 💡 [핵심] 회원사/비회원사 엄격 필터링
- 엑셀 내 회원내역 값이 존재하더라도, 그 값이 `"비회원"`일 경우에는 회원사 자격 배지를 출력하지 않고 일반 비회원(`"-"`)으로 엄격히 제한합니다. 값이 유효하고 비회원이 아닐 때만 보라색 **`회원사`** 배지를 비고 란에 노출합니다.

#### 📐 [핵심] HTML `rowSpan` 기반의 수직 중앙 정렬 (`align-middle`) 테이블 레이아웃
- **구조 개편**: 세부내역 배지가 세로 1열로 늘어나면서 왼쪽의 사업 구분 배지가 어정쩡하게 한쪽으로 쏠리는 것을 원천 방지하기 위해 HTML 테이블의 정석적인 **다중 `<tr>` 병합 렌더링**을 수행합니다.
- **rowSpan 자동 산출**: 각 고객사가 이수한 부문(공개교육, 사내교육, 현장교육 중 실적 > 0인 부문)의 갯수를 구해 `rowSpan` 값(1~3)을 구합니다.
- **렌더링 배분**:
  - 첫 번째 부문 수강 행 그릴 때: `고객사명(rowSpan) | 첫번째 사업 구분 | 첫번째 세부내역 | 인증현황(rowSpan) | 비고(rowSpan)`를 하나의 `<tr>`에 렌더링합니다.
  - 두/세 번째 부문 수강 행 그릴 때: 병합 열을 제외하고 `[사업 구분 | 세부내역]` 만을 별도의 `<tr>`로 연이어 그려줍니다.
  - 이로써 브라우저 자체의 `align-middle` 속성에 의해 좌측의 사업구분 배지들이 오른쪽 세부내역의 세로 크기에 맞춰 **완벽하게 그 세로 높이의 정중앙에 정확히 정렬**됩니다.

#### 📐 [핵심] 세부내역 연도별 그룹화 및 기하학적 대칭 스타일 규칙
- **연도 구분선**: 한 셀 내부에서 교육과정들이 연도별로 묶여 세로 나열될 때, 연도 경계 사이에 연한 실선(`border-t border-slate-100 pt-3`)을 부착하여 구획을 나눕니다.
- **글자 크기 통일**: 연도 배지의 글자 크기를 `text-[11px]`로 일관되게 맞춰 세부내역 텍스트와 균형을 맞췄습니다.
- **20px 대칭 여백**: 
  - `[셀 왼쪽 실선 경계] ◀-- 20px --▶ [연도박스]` (`pl-5` 패딩 적용)
  - `[연도박스] ◀-- 20px --▶ [오른쪽 과정명 목록]` (`gap-5` 가로 갭 적용)
  - 두 여백의 간격을 **20px로 완벽히 동일화**하여 시각적 비례 밸런스를 수립합니다.

#### 📐 테이블 가로 너비 최종 배분 비율 (고정 레이아웃 `table-fixed`)
- **고객사명** : `20%` (좌측 정렬 `text-left px-6 py-4`)
- **사업 구분** : `18%` (가운데 정렬 `text-center px-6 py-4`)
- **세부내역** : `42%` (연도 배지 좌측 정렬, 과정명 좌측 정렬 `pl-5 pr-6 py-4`)
- **인증 현황** : `10%` (가운데 정렬 `text-center px-4 py-4`)
- **비고** : `10%` (가운데 정렬 `text-center px-4 py-4`)
